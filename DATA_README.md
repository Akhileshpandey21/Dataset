# Dataset: label-free accuracy estimation for tabular classifiers under natural shift

**File:** `dataset_label_free_accuracy_estimation.csv` (1,710 rows; one row = one model evaluated on one domain for one seed).
Rows: 3 tasks x 3 scenarios x 5 seeds x 6 models x (1 in-distribution + 4 to 8 shifted domains) = 270 in-distribution + 1,440 shifted.

## Provenance
- **Raw data:** US Census Bureau, American Community Survey (ACS) Public Use Microdata Sample, 1-Year person files, accessed through the open-source **Folktables** package (Ding, Hardt, Miller, Schmidt, NeurIPS 2021) from census.gov. Raw PUMS files are public and are *not* redistributed here.
- **Tasks:** `ACSIncome` (income > USD 50k), `ACSPublicCoverage` (public health coverage among low-income people under 65), `ACSEmployment` (employed). Folktables default feature sets.
- **Scenarios:** `geo` (source CA 2018 -> TX, NY, FL, IL, PA, OH, MS, WA 2018); `temporal` (source CA 2014 -> CA 2015-2018); `geotemporal` (source CA 2014 -> TX, NY, MS, WA 2018).
- **Sampling per seed:** 10,000 train, 3,000 source validation, 5,000 in-distribution test, 5,000 rows per target domain.
- **Collection method:** generated by the accompanying Google Colab notebook (`label_free_accuracy_estimation_colab.ipynb`); six learners (LogReg, RandForest, MLP, XGBoost, LightGBM, CatBoost) with default hyperparameters. Each row stores the *derived* quantities below, not raw census rows.
- **Licence note:** the derived table contains no individual-level records. Verify Census data-use terms and add your chosen licence (e.g. CC BY 4.0) before depositing in a repository.

## Columns
| Column | Meaning |
|---|---|
| task, scenario, seed, model | Experimental factors |
| domain | `ID` = in-distribution test set; otherwise `STATE-YEAR` target |
| shifted | 0 for `ID`, 1 for shifted targets |
| true_acc | Actual accuracy on the 5,000 target rows (labels revealed) |
| acc_val | Accuracy on the labeled source validation set |
| true_accuracy_drop | `acc_val - true_acc` (positive = accuracy fell on target) |
| est_naive | Naive estimate = `acc_val` |
| est_AC | Average confidence on target |
| est_AC_TS | Average confidence after temperature scaling (fit on validation) |
| est_DoC | Difference of confidences: `acc_val - (conf_val - conf_target)` |
| est_ATC | Average thresholded confidence |
| est_AGREE | Agreement rate between model A and bootstrap-trained model B on target |
| est_AGREE_DoC | `acc_val - (agree_val - agree_target)` |
| conf_drop | `conf_val - conf_target` (mean confidence) |
| agree_drop | `agree_val - agree_target` |
| shift_auc | Domain-classifier AUC (0.5 none, 1.0 fully separable) |
| auc_valid | **False** for ACSPublicCoverage geo/geotemporal targets: that task includes the state code (ST), so AUC = 1.0 is an artifact. Exclude these rows from any analysis using `shift_auc`. |
| prev_shift | Positive-class prevalence of target minus source |
| fit_s | Seconds to fit models A and B |

All estimates are proportions in [0, 1]. Estimation error in accuracy points = `100 * (est_X - true_acc)`.
